内部自检与真实项目验收不同：工具目录不是一个正在工作的已接入项目，在其根目录直接运行 MCP 自检可能打印“缺少当前任务表”的问题计数，但仍通过服务内部自检。真正的项目应另运行 `validate_handoff`，确认 `passed: true`，并查看问题清单；不要只看进程退出码。

这些检查不是完整的保密审计，也没有证明所有可识别写入均无误。测试脚本使用失败场景时可能打印预期守卫提醒，应以对应断言与退出码判断。
