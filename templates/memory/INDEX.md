# Project Memory Index

This index locates durable project facts and reusable completed-task summaries. It is not a transcript and does not duplicate active workstreams; current state is in `handoff-current.md`.

## Stable project facts

- <fact name>: `memory/stable/<file>.md`

## Completed and historical summaries

- <summary name> (<YYYY-MM-DD>): `memory/completed/<file>.md`
- Reusable completed summaries: `memory/completed/`
- Historical detailed handoffs: `handoffs/archive/`

## Recording rule

Write durable memory only when the user explicitly requests it, or the active handoff already specifies it. Eligible content includes stable facts, reusable methods and selected completed summaries; it is not an automatic output of every task. Do not copy the current dashboard, routine milestones or full conversation text here.
